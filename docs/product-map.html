SYSTEM ARCHITECTURE

How it all fits together

VirtValidate runs as a self-contained Podman appliance inside the customer environment. It SSHes into source VMs to capture baselines, then validates target VMs after migration. All AI inference happens locally — no data ever leaves the customer network.

END-TO-END WORKFLOW

The migration validation lifecycle

Five distinct phases from initial enrollment through final validation. Each phase produces an artifact the next phase depends on.

PHASE 01
Enroll VMs
Add VMs via manual entry, CSV, or RVTools. Distribute SSH public key. Tag with current platform (VMware).
PHASE 02
Build Baseline
Scheduler SSHes in twice daily for 3-7 days. Captures services, ports, mounts, cron, network, performance.
PHASE 03
Plan Migration
LLM groups VMs into waves by network, storage, and dependency constraints. Generates MTV-ready YAML.
PHASE 04
Migrate Wave
User applies MTV plan or runs preferred migration tool. Marks wave complete in VirtValidate when done.
PHASE 05
Validate + Report
Auto-validates against baseline. LLM generates per-VM verdict and CISO-ready wave report with PDF export.

TECHNOLOGY STACK

Built on proven open source

Every component is open source and freely available. No proprietary dependencies. No vendor lock-in.

FRONTEND
React 18 + Vite
Single-page application with Tailwind, served by nginx. WCAG AA compliant.
BACKEND
Python 3.12 + FastAPI
Async API, SQLAlchemy ORM, Pydantic validation, OpenAPI auto-docs.
DATABASE
PostgreSQL 16
Relational data, JSONB for flexible snapshots, full audit trail.
AI INFERENCE
Ollama + Llama 3 8B
Local model serving. Air-gapped. vLLM upgrade path for scale.
SSH ENGINE
Paramiko + Ed25519
Modern SSH library with strong key crypto. Restricted sudo on targets.
SCHEDULER
APScheduler
In-process job scheduling for baseline collection runs.
CONTAINERS
Podman + Quadlet
Rootless, daemonless containers. Systemd-native production deployment.
REPORTS
WeasyPrint
HTML-to-PDF rendering for CISO-ready wave reports.
