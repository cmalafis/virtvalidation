How to access the dashboard:

{{- if .Values.route.enabled }}
1. OpenShift Route created. Get the host:

     oc get route {{ include "virtvalidate.fullname" . }} -n {{ .Release.Namespace }} -o jsonpath='{.spec.host}'

{{- else if .Values.ingress.enabled }}
1. Ingress created. Configure DNS for {{ .Values.ingress.host }}, then visit:

     https://{{ .Values.ingress.host }}/

{{- else }}
1. No Route or Ingress configured. Port-forward for local access:

     kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "virtvalidate.fullname" . }}-frontend 3000:{{ .Values.frontend.service.port }}

   Then open http://localhost:3000/.

{{- end }}

2. Verify the FIPS posture (federal deployments):

     kubectl exec -n {{ .Release.Namespace }} deploy/{{ include "virtvalidate.fullname" . }}-backend -- curl -fsS http://localhost:8000/api/system/fips-status

3. The SSH public key for managed VMs lives in Settings → SSH Public Key.
   Distribute it to every VM you want to validate before triggering the
   first capture.
